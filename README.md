## ◈ What is nVision?

nVision is a seizure-detection algorithm developed in 2010 and tested in three mouse models of epilepsy. It has since been used in multiple peer-reviewed studies involving mouse and rat models of epilepsy, as well as control animals.

## ◈ Installation
nVision is available in three formats: MATLAB, Python and Linux.

### MATLAB 
nVision requires a current MATLAB installation with these toolboxes:

- Signal Processing
- Deep Learning
- Statistics and Machine Learning

1. Download and unzip the repository.
2. Set MATLAB's Current Folder to the nVision folder.
3. Run `nvision2013_parameters_5_vs_26_g_new.m`.

### Python port (Linux / WSL)

The Python port runs without MATLAB and supports the 200, 500, and 1000 Hz
processing paths.

```bash
cd nVision_core/python_port
bash setup_linux.sh
bash run_nvision.sh /path/to/recording.dat --rate 200 --output outputs/result.json
```

Replace `200` with the recording's acquisition rate (`500` or `1000` when
applicable). The launcher uses a local Python virtual environment created by
`setup_linux.sh`.

For the desktop GUI on Ubuntu or another native Linux desktop session:

```bash
cd nVision_core/python_port
chmod +x setup_linux.sh run_nvision.sh run_nvision_gui.sh
./setup_linux.sh
./run_nvision_gui.sh
```

The GUI requires an X11 or Wayland display session and uses the same Python
processing pipeline as the CLI. It writes the JSON result, feature CSV, and
analysis MAT file to the selected output folder.

See [Python and Linux usage](docs/python-linux-usage.md) for Windows
PowerShell, native Ubuntu, and WSL instructions.

The telemetrically acquired iEEG signals are filtered and divided into 2‐s segments with a 1‐s overlap. Features are extracted from each segment, normalized, and fed to the ANN for classification. The ANN output undergoes sliding window‐thresholding to produce the time coordinates of the detected events. (D) The architecture of the constructed ANN.
